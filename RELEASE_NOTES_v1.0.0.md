# Selenium Serenity Automation Framework v1.0.0

## Overview

Version 1.0.0 is the first stable release of the Selenium Serenity automation
framework and the GitHub-based CI/CD baseline for later Jenkins, Docker, Nexus
and Selenium Grid phases.

## Highlights

- Java 21 and Maven.
- Selenium WebDriver UI automation.
- Serenity BDD reports and screenshots.
- Cucumber smoke, sanity and regression tags.
- GitHub Actions for pull requests and branch pushes.
- Manual workflow dispatch.
- Report and diagnostic artifacts.
- GitHub Job Summary.
- GitHub Pages publication from successful `main` runs.
- Final quality gate.
- Repository documentation and governance.
- Semantic Versioning through `VERSION`.

## Known limitations

- Chrome is the current CI browser.
- Jenkins, Nexus, Selenium Grid and Dockerized browsers are planned later.
- GitHub Pages keeps the latest successful public report.

## Roadmap

Enterprise CI/CD with Jenkins, Docker, Nexus, Selenium containers and VNC.
