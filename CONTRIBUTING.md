# Contributing

Create work from `develop` using `feature/`, `fix/`, `docs/`, `test/`, `refactor/` or `ci/`.

Before opening a PR, run smoke tests, verify Serenity output, run `git diff --check`, and confirm no secrets or generated reports are committed.

Commit examples: `feat: add checkout tests`, `fix: correct assertion`, `ci: optimize workflow`, `docs: update architecture`.
